# Guitar Studio AI 설치 및 사용 설명서

Guitar Studio AI는 기타 연주자를 위한 **로컬 음악 분석 플레이어**입니다. 음악 파일을 열면 이 기기 안에서 BPM, 박자, Key, 코드 진행을 분석하고, 원곡 박자에 맞춘 클릭(메트로놈)을 들으며 연습할 수 있습니다.

- 음악 파일은 외부 서버로 전송되지 않습니다. 계정이나 인터넷 연결 없이 사용합니다.
- 원본 음악 파일은 읽기만 하며 절대 수정하지 않습니다.
- 지원 포맷: MP3, WAV, FLAC, M4A, AAC, OGG (OGG는 구형 Safari/iOS 16 이하에서 재생되지 않을 수 있음)

---

## 1. 설치

### Windows 10 / 11
1. `Guitar Studio AI_0.1.0_x64-setup.exe` 를 실행합니다.
2. 설치가 끝나면 **바탕화면 바로가기**와 **시작 메뉴** 아이콘이 생성됩니다.
3. 처음 실행할 때 Microsoft Edge WebView2 런타임이 없으면 설치 프로그램이 자동으로 설치합니다(Windows 11 은 기본 포함).
4. 서명되지 않은 빌드는 SmartScreen 경고가 나올 수 있습니다: "추가 정보 → 실행".
5. 제거: 설정 → 앱 → Guitar Studio AI → 제거 (바탕화면 바로가기도 함께 삭제됨).

### macOS (11 Big Sur 이상, Intel/Apple Silicon 공용)
1. `Guitar Studio AI_0.1.0_universal.dmg` 를 열고 앱을 **응용 프로그램** 폴더로 끌어 놓습니다.
2. 서명/공증되지 않은 빌드는 처음 열 때 차단될 수 있습니다: Finder 에서 앱을 **Control+클릭 → 열기**.

### Android 스마트폰·태블릿 (PWA)
1. Chrome 으로 앱 주소를 엽니다(아래 "PWA 배포" 참고).
2. 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**.
3. 설치 후에는 인터넷 없이도 실행됩니다.

### iPhone / iPad (PWA)
1. **Safari** 로 앱 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 전체 화면 앱처럼 동작하고 오프라인에서도 열립니다.

> **PWA 배포에 대해**: 휴대폰 브라우저는 보안상 *HTTPS 주소*(또는 같은 기기의 localhost)에서 열린 웹앱만 설치할 수 있습니다. 앱 파일(`dist` 폴더)은 정적 파일일 뿐이며 음악 파일이나 분석 데이터는 어떤 서버로도 보내지 않습니다. 방법은 두 가지입니다.
> - (권장) GitHub Pages 같은 무료 정적 호스팅에 `dist` 폴더를 올리고 그 주소로 한 번 접속해 설치 → 이후 완전 오프라인 사용.
> - PC 에서 `npm run preview -- --host` 로 같은 Wi‑Fi 에 띄운 뒤 접속(이 경우 HTTPS 가 아니므로 Android Chrome 에서는 "바로가기"로만 추가되고, iOS 에서는 오프라인 캐시가 동작하지 않습니다).

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 | 로고, **열기**(파일), **폴더**, **분석**, 설정(⚙), 테마(☀/☾) |
| 중앙 | 곡 정보, BPM · 박자 · Key · 현재 코드 · 마디/박, 파형, 전체 코드 진행, 코드 표, A-B 구간 |
| 하단 | 재생 위치, 이전/재생/다음, 배속, 피치, A·B·반복, 메트로놈, 클릭만, 볼륨 |
| 탭 | 플레이어 · 카피 모드 · 분석 리포트 · 라이브러리 · 설정 (모바일은 하단 탭) |

**단축키**: `Space` 재생/일시정지 · `←/→` 5초 이동(Shift: 1초) · `[` A 지정 · `]` B 지정 · `L` 반복 · `M` 클릭 · `N` 다음 곡 · `1/2/3` 탭 전환

## 3. 음악 불러오기와 라이브러리
- **열기** 버튼, **폴더** 버튼, 또는 창에 파일을 **끌어다 놓기**.
- 라이브러리: 재생목록(순서 변경 ▲▼), 폴더별, 최근 재생, 즐겨찾기(★), 검색.
- 곡마다 **마지막 재생 위치**, **연습 메모**, **분석 결과**, **반복 구간**, **마커**가 자동 저장됩니다.
- 앱을 다시 열면 마지막 곡과 탭이 복원됩니다.
  - 데스크톱 앱: 파일 경로로 자동으로 다시 엽니다.
  - Chrome/Edge(PC): 파일 접근 권한을 한 번 허용하면 다시 엽니다.
  - 휴대폰/Safari: 설정의 **음원 사본 보관**을 켜 두면(모바일 기본값) 자동으로 열립니다. 끈 경우 "파일 다시 선택" 안내가 나오며, 같은 파일을 고르면 분석·구간·메모가 그대로 연결됩니다.

## 4. AI 분석
**분석** 버튼을 누르거나(설정에서 "자동 분석"이 켜져 있으면 곡을 열 때 자동) 진행률이 표시되며, 분석 중에도 재생할 수 있습니다. 3~5분 곡은 일반 PC 에서 수 초 정도 걸립니다.

| 항목 | 표시 |
|---|---|
| BPM | 소수점 BPM, 일정/변화 여부, 구간별 BPM(리포트), 신뢰도 |
| 박자 | 2/4, 3/4, 4/4, 5/4, 6/8 등 자동 추정, 다운비트(마디 첫 박) |
| Key | 장/단조, Camelot 표기, 구간별 Key(리포트), 신뢰도 |
| 코드 | Major, m, 7, maj7, m7, sus2, sus4, add9, dim, aug, m7b5, m6, 6, 5, 슬래시(베이스) 코드, 신뢰도 |
| 곡 구조 | Intro/Verse/Chorus/Bridge/Outro **추정**(항상 "?" 표시) |

- **AI 추정**(신뢰도 %, 색: 초록 높음 / 노랑 보통 / 빨강 낮음)과 **사용자 확정**(파란색)을 구분해 표시합니다.
- 분석하지 않은 값은 "—" 로 표시하며 임의의 값을 보여주지 않습니다.

### 결과 수정
- **BPM 수정**: ÷2 / ×2(하프·더블 타임 보정), 직접 입력, 탭 템포, 클릭 싱크 미세 이동(±5/20ms).
- **박자 수정**: 박자표 선택, "현재 위치의 비트를 1박으로" 로 다운비트 정정.
- **Key 변경**: "코드도 함께 이조"를 켜면 모든 코드 표시가 새 Key 로 변환됩니다(카포/다른 키 연습). 끄면 Key 이름만 정정합니다.
- **코드 수정**: 코드 표에서 코드 이름을 눌러 입력(예: `G`, `Em7`, `D/F#`, `Cmaj7`, `N.C.`). "분할"로 현재 위치에서 코드 구간을 나눕니다.
- **분석 실패 시**: BPM 수정 창에서 BPM·첫 박 위치·박자를 직접 입력하면 클릭 기능을 그대로 쓸 수 있습니다.
- 피치를 바꾸면 Key/코드 표시도 반음 단위로 따라 바뀝니다.

### 내보내기
- 코드 표: **복사**(마디별 `| G | D | Em | C |`), **TXT**, **CSV**
- 리포트: **TXT**, **JSON**

## 5. 원곡 동기화 클릭(메트로놈)
- 하단 메트로놈 버튼(또는 `M`)으로 ON/OFF. 분석 후 사용할 수 있습니다.
- 클릭은 분석된 **실제 비트 위치**에 맞춰 울리며, 템포가 변하는 곡도 따라갑니다.
- 설정 → 메트로놈 클릭: 음색(전자/우드블록/스틱/카우벨/킥·스네어), 간격(2박마다·1박마다·8분·16분·셔플), 첫 박 강조, 음량, **카운트 인**(1~2마디), 싱크 보정(블루투스 이어폰 지연 보정용).
- **클릭만**: 원곡 소리를 끄고 클릭만 들을 수 있습니다.
- 배속·피치를 바꿔도 클릭은 원곡 박자에 고정됩니다(재생과 클릭을 같은 오디오 스레드에서 샘플 단위로 합성).

## 6. 카피 기능
- **배속**: 0.5 ~ 2.0배 (음정 유지)
- **피치**: −12 ~ +12 반음, 가운데 숫자를 누르면 원래 음정으로
- **A-B 반복**: 파형을 드래그하거나 `[` `]`, 반복 횟수(무한/2~20회), "비트에 맞춤", 구간 저장 및 구간별 메모
- **파형**: 클릭 이동, Ctrl(⌘)+휠 또는 돋보기 버튼으로 확대/축소, 아래 전체 파형에서 위치 이동, 마디 번호·비트·코드 변경 지점·마커 표시
- **마커**: 현재 위치에 저장, 눌러서 이동
- **악기 강조**: 하단의 기타 · 베이스 · 건반 · 드럼 · 보컬 버튼을 누르면 그 악기가 크게, 나머지는 작게 들립니다. **원음**(또는 같은 버튼 한 번 더)으로 원래대로 돌아가고, **세기** 슬라이더로 정도를 조절합니다. 배속·피치·반복·클릭과 함께 쓸 수 있습니다.
  - AI 음원 분리가 아니라, 악기가 주로 차지하는 **음역대**와 **좌우 위치**(보컬·베이스는 가운데, 기타는 좌우로 퍼진 경우가 많음)를 이용해 강조하는 방식입니다. 그래서 곡에 따라 효과가 다릅니다.
  - 효과가 뚜렷한 편: 베이스, 보컬, 드럼(킥·심벌). 약한 편: 기타, 건반(음역대가 서로 겹침). 같은 음역의 다른 악기는 함께 커집니다.

## 7. 카피 모드 탭
현재 BPM(배속 반영), Key, 마디, 남은 시간(반복 중이면 구간 남은 시간), **현재 코드**(큰 글씨), **다음 코드**와 "N박 후" 카운트다운(바뀌기 한 마디 전부터 강조), 박자 표시등, 다음 코드 목록.

## 8. 분석 리포트 탭
곡 정보 요약, 대표 코드 진행, 곡 구조·코드·Key 타임라인(눌러서 이동), 구간별 BPM, 마디별 코드 진행.

## 9. 데이터 저장·백업
- 모든 데이터는 이 기기에만 저장됩니다(데스크톱: 앱 데이터 폴더, 브라우저/PWA: IndexedDB).
- 설정 → **백업 파일 내보내기**: 분석 결과·코드 수정·구간·메모·설정을 JSON 파일로 저장합니다. USB, 메일 등으로 다른 기기에 옮긴 뒤 **백업 가져오기**로 복원합니다. 음악 파일은 백업에 포함되지 않으며, 다른 기기에서 같은 파일(이름·크기·수정 시각 동일)을 열면 분석 결과가 연결됩니다.
- 기기 간 자동 동기화 기능은 없습니다(서버를 쓰지 않기 때문).

## 10. 문제 해결
| 증상 | 해결 |
|---|---|
| 파일을 재생할 수 없음 | 해당 기기/브라우저가 그 형식을 지원하지 않거나 파일이 손상된 경우입니다. MP3/WAV 로 변환해 보세요. |
| 클릭이 미세하게 어긋나 들림 | 블루투스 장치 지연일 수 있습니다. 설정 → 클릭 싱크 보정, 또는 BPM 수정 창의 ±ms 로 비트 전체를 이동하세요. |
| BPM 이 절반/두 배로 나옴 | BPM 수정 → ÷2 / ×2 |
| 마디 시작이 어긋남 | 박자 수정 → "현재 위치의 비트를 1박으로" |
| 코드가 틀림 | 코드 표에서 직접 수정(사용자 확정으로 저장) |
| iOS 에서 앱이 데이터를 잃음 | iOS 는 오랫동안 사용하지 않은 웹앱 데이터를 지울 수 있습니다. 주기적으로 백업 파일을 내보내 두세요. |
